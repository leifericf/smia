# Preface

This manual is itself a clj-book manuscript: every page you are reading was
produced by building the Markdown sources under `manual/` with clj-book.
It is the platform dogfooding its own affordances, and it doubles as a
regression test — if a feature breaks, this book stops building.

The manual is organized into parts. The first part covers authoring; the second
covers configuration, theming, and the build commands; the third covers the
structural and visual apparatus of a long-form book. An appendix catalogs the
error types, and the back matter holds a bibliography and an index — both
generated by clj-book from the sources.

Front matter like this preface is numbered in roman numerals; the body switches
to arabic numerals at the first chapter.
