[#ch-configuration]
== Configuration

Manuscript metadata and build configuration live in two complementary places.

=== `book.adoc` — authorial metadata

The AsciiDoc document header carries author-facing metadata: title, authors, revision, custom document attributes. Anything that affects the rendered manuscript content belongs here.

[source,asciidoc]
----
= My Book Title
Author One; Author Two
v1.0.0
:doctype: book
:lang: en
:toc:
----

=== `book.edn` — build configuration

`book.edn` is an open Clojure map of build-orthogonal configuration. Required keys must be present and valid; additional keys are preserved.

==== Required keys

[%header,cols="1,1,3"]
|===
|Key |Type |Purpose

|`:book/slug`
|String
|Output directory and PDF filename component. Must be filesystem-safe.

|`:book/title`
|String
|Human title used in PDF metadata and site `<title>` elements.

|`:book/chapters`
|Vector of strings
|Chapter source paths relative to `book-root`, in the order they should appear.
|===

==== Tier-2 layout keys

A deliberately small set of layout keys, translated symmetrically to both targets:

[%header,cols="1,1,2"]
|===
|Key |Allowed values |Meaning

|`:page-size`         |`:a4` `:letter` `:digest` |PDF page size (site derives max-width from typography tokens)
|`:page-margins`      |String (e.g. `"0.75in"`)  |PDF page margins
|`:chapter-opener`    |`:page-break` `:inline`   |Whether chapters start on a new page
|`:toc-depth`         |Integer                   |Section depth included in the TOC
|`:code-line-numbers` |Boolean                   |Show line numbers on code listings
|`:admonition-style`  |`:icon` `:label`          |Admonition presentation style
|===

Unknown layout values produce a warning in the build metadata but do not fail the build.

==== Open-map semantics

Additional custom keys are preserved as-is, allowing manuscript-specific metadata without coupling to `clj-book`.

[source,clojure]
----
{:book/slug      "my-book"
 :book/title     "My Book"
 :book/chapters  ["chapters/01.adoc" "chapters/02.adoc"]
 :page-size      :a4
 :custom/team    "Platform Engineering"}
----
